# Portfolio frontend

Run `npm install` and `npm run dev` from the repository root. Vite serves `index.html` and `src/main.jsx`. The same command starts the Express API.

The six page sections live in `src/sections/`. Edit the portfolio content in `src/data/`, shared components in `src/components/` and styles in `src/styles/index.css`. The downloadable CV and optimized images are in `static/`.

The [root README](../README.md) includes the animation guide and photo replacement instructions. See [deployment](../DEPLOYMENT.md) for build and hosting settings.
